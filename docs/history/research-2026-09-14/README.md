Two things to know before reading them.

**Report 3 is extracted text, not the original.** It arrived as a PDF, whose binary is not kept here.
The extraction put one word per line and has been reflowed, so its line breaks are not the author's
and its reference list at the end is run together. The wording is unaltered.

**Report 1 contains broken citation markers.** Strings such as `citeturn25academia29` are
artifacts of the tool that produced it, not text. They are left in place rather than cleaned, so the
file stays a faithful copy; the synthesis lists the sources in a readable form.

Neither these reports nor the synthesis is a decision. See the synthesis for what they dispute and
what is still open.
